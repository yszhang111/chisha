# 吃啥 · 微信小程序版

原生 WXML / WXSS / JavaScript。Canvas 2D 在屏幕外生成轮盘图片，页面使用普通图片和 WXSS 过渡显示轮盘。无需 npm 构建、服务器、云开发或 API Key，所有餐厅名单和候选日期只保存在当前微信本地。

## 导入运行

1. 安装并打开[微信开发者工具](https://developers.weixin.qq.com/miniprogram/dev/devtools/download.html)，选择「小程序」→「导入项目」。
2. 项目目录选择本文件所在的 **miniprogram 文件夹**，不是仓库最外层。
3. 使用项目中已配置的你自己的小程序 AppID，选择「不使用云服务」，导入后点击「编译」。如复制给其他账号使用，需换成对应账号的 AppID；无 AppID 时可按开发者工具提示使用测试模式。
4. 使用基础库 3.7.6 或较新的稳定 3.x 版本。项目配置已经指定 3.7.6，开发者工具可能会下载对应基础库。
5. 无需点击「构建 npm」，无需启动网页版预览服务，也无需填写服务器域名。

项目保留了你在开发者工具中填写的 AppID 和本地设置。复制给其他账号时，在开发者工具「详情」或 `project.config.json` 中更换对应账号的 AppID；代码不需要 AppSecret 或私钥。

## 使用规则

- **餐厅必填**：输入后按回车／完成键或点击加号。支持逗号、顿号、分号和换行批量输入；最多 24 家，自动去重，每个名称最多 30 个字符。
- **日期选填**：在日历中多选今天起的候选日期，最多 31 个，支持跨月和跨年；过期日期会在恢复小程序或抽选前自动清除。
- 日历采用日期栏下方展开的紧凑月历，每周固定七列，点日期可选中／取消，点击「选好了」或日期栏收起。
- **午餐／晚餐选填**：勾选「这顿也随机」，轮盘就会在午餐、晚餐中抽选；不勾选时隐藏该轮盘。
- **没填写的轮盘直接隐藏**；点击「转一转，开饭！」后，所有已设置的轮盘同时开始转动。
- 每个轮盘随机生成转动距离与初始转速，按匀减速运动逐渐停下，停稳后根据指针所在扇区读取结果。落点覆盖整个圆周，正中央、靠近分界线的位置都可以自然出现；各选项保持等概率。
- 支持删除餐厅、删除日期、重新抽选、复制结果与重置。分享按钮分享的是小程序入口和本次餐厅名称，接收者进入后用自己的名单开始；不会自动同步你的整份名单。
- 原生小程序缓存与网页版浏览器缓存相互独立。清理小程序数据或更换设备后，选项不会自动恢复。

## 结构

```text
miniprogram/
├── project.config.json     开发者工具导入配置
├── app.js / app.json / app.wxss
├── sitemap.json
├── assets/avatar.png       去掉筷子的新版饭碗头像
├── pages/index/            首页、内嵌月历、结果与使用说明
├── components/roulette/    轮盘图片生成与旋转动画
└── utils/
    ├── model.js            名单、日期、转动参数和停点结果读取
    └── draw-wheel.js       绘制轮盘
```

饭碗头像也可在微信公众平台设置为小程序头像；页面内的图片不会自动修改微信后台设置。

分享卡片使用微信默认的当前页面截图作为封面，标题包含本次抽中的餐厅。开发者工具中的「虚拟好友」是模拟分享预览；真实的微信选人界面与分享卡片效果需要通过手机预览确认。

## 检查

在仓库根目录运行：

```sh
npm run check
npm test
```

静态检查会检查 JavaScript 语法、JSON、页面与组件路径、WXML 标签嵌套和事件绑定。Node 测试覆盖日期边界、多选、必填校验、选填轮盘隐藏、同步抽选、指针落点、重复点击、存储异常和后台／卸载时的动画收尾。

**验证范围：**已通过静态检查和 28 项自动测试，并使用本机微信开发者工具附带的 WXML／WXSS 编译器验证页面和样式可编译。测试包含转动参数与选项数量无关、停稳后按角度读取结果、中心与边界落点不被修改、均匀转动距离覆盖所有选项、图片导出失败后重试，以及所有轮盘图片就绪后同步启动。尚未完成微信模拟器交互和 iOS／Android 真机验证。导入后请重点检查：输入法完成键、日历多选、三轮盘同时转动、停止后的指针、后台返回、复制与分享。

本项目使用自己的按钮样式，不启用 `app.json` 的 WeUI v2 默认组件主题，避免默认固定按钮宽度影响餐厅快捷选项、加号和日历布局。修改全局配置后，请在开发者工具点击「编译」。

页面采用上下布局：上方 `scroll-view` 承载表单、轮盘和结果，下方操作栏单独占据空间并预留底部安全区，不覆盖滚动内容。屏幕内的轮盘是普通 `image`，固定指针和中心字独立显示；Canvas 位于屏幕外，仅在选项变化时生成图片。旋转角度直接绑定到图片样式，过渡曲线模拟匀减速；轮盘组件停止后返回所在扇区，页面据此显示结果。使用说明通过 `root-portal` 显示。修改后在开发者工具点击「编译」，检查滚动到最底部时三个轮盘和按钮均可完整看到，说明弹层也能盖住轮盘。
