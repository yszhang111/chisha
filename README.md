# 吃啥

餐厅、日期、午餐晚餐，三个轮盘帮你决定下一顿。

纯 HTML、CSS、JavaScript 网站，无后端依赖，可自行部署到任何静态网站服务器。

## 本地运行

安装 Node.js 18 或更高版本后，在项目根目录运行：

```sh
npm run dev
```

浏览器打开 <http://127.0.0.1:4173/>。无需安装 npm 依赖。

## 自行部署

将 `dist/` 里的全部文件上传到你的服务器网站目录即可：

```text
dist/
├── index.html
├── style.css
├── app.js
└── favicon.svg
```

- 网站根目录应指向 `dist/`，或把其内容复制到现有网站根目录。
- 这是静态网站，无需构建命令、数据库、API Key 或 OpenAI 服务。
- 资源使用相对路径，也可以部署在子目录下。
- `server.mjs` 仅用于本地开发预览，不需要上传到静态服务器。
- 字体优先使用 Google Fonts；无法加载时自动使用系统中文字体，网站仍可使用。

## 功能

- 餐厅必填：输入名称后按回车或加号添加，支持逗号、顿号、分号、换行批量输入；最多 24 家，自动去重。
- 日期选填：打开日历选择候选日期，最多 31 个；没有选择日期时，不显示日期轮盘。
- 午餐／晚餐选填：勾选「这顿也随机」后，显示午餐／晚餐轮盘；取消勾选后隐藏。
- 点击「转一转，开饭！」，所有已设置的轮盘同时转动并随机产生结果。
- 支持复制结果、重新抽选、删除选项和重置；选项自动保存在当前浏览器。
- 适配手机和桌面，并支持系统减少动态效果偏好。

## 检查

```sh
npm run check
```

已通过浏览器交互检查：餐厅必填、日历多选、可选轮盘显示与隐藏、三轮盘同步转动、指针与结果一致、刷新恢复选项，以及手机布局。
